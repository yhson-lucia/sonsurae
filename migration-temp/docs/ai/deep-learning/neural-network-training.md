## 1. 학습

- **학습**: 데이터에서 가중치 매개변수의 값을 자동으로 결정한다는 뜻
- **데이터**: 머신러닝에서는 사람의 개입을 최소화하고 수집한 데이터로부터 패턴을 찾으려 시도
- **특징**: 입력 데이터에서 본질적인 데이터를 정확하게 추출할 수 있도록 설계된 변환기
  - 이미지의 특징은 보통 벡터로 기술. SIFT, SURF, HOG 등이 있음
  - 특징을 사용해 이미지를 벡터로 변환하고, 변환된 벡터를 SVM, KNN 등 지도 학습 분류기로 학습할 수 있음

![머신러닝 vs 딥러닝의 데이터 흐름](images/neural-network-training-01.webp)

### 1.1 훈련 데이터 vs 시험 데이터

- **훈련 데이터(Training data)** 와 **시험 데이터(Test data)** 를 나눠야 함
- 범용적으로 사용할 수 있는 모델이 목적이기 때문에, 아직 보지 못한 데이터(훈련 데이터에 포함되지 않은 데이터)로 문제를 올바르게 풀어내는 능력이 중요
- 한쪽 데이터셋에만 지나치게 최적화된 상태를 **과대적합(Overfitting)** 이라 함

## 2. 손실 함수

- **손실 함수**: 신경망에서 최적의 매개변수 값(가중치, 편향)을 찾는 **판단 근거**
- 매개변수를 정하기 위한 판단 근거를 수치로 표현한 지표를 함수로 나타낸 것
- 신경망 성능의 **'나쁨'을 나타내는 지표**. 현재 신경망이 훈련 데이터를 얼마나 잘 처리하지 **못하느냐**를 나타냄
- 일반적으로 **오차제곱합**과 **교차 엔트로피 오차**를 사용

### 2.1 오차제곱합 (SSE)

**Sum of Squares for Error**: 가장 많이 쓰이는 손실 함수.

$$\text{SSE} = \sum_{i=1}^{n} (y_i - \hat{y}_i)^2$$

| 기호 | 의미 |
|---|---|
| $n$ | 데이터 포인트의 수 |
| $y_i$ | $i$번째 **신경망의 출력** (예측값) |
| $\hat{y}_i$ | $i$번째 **정답 레이블** (실제값) |
| $(y_i - \hat{y}_i)$ | 잔차(residual) 또는 오차(error) |

> **표기 주의**: 책마다 다름. 일부 책에서는 $y_i$를 정답, $\hat{y}_i$를 예측으로 표기함. 이 노트는 『밑바닥부터 시작하는 딥러닝』의 표기 방식을 따름 ($y_i$ = 신경망 출력, $\hat{y}_i$ 또는 $t_i$ = 정답).

**벡터 표기법**: 벡터 $\mathbf{y}$와 $\hat{\mathbf{y}}$에 대해

$$\text{SSE} = \|\mathbf{y} - \hat{\mathbf{y}}\|^2 = (\mathbf{y} - \hat{\mathbf{y}})^T (\mathbf{y} - \hat{\mathbf{y}})$$

### 2.2 평균 제곱 오차 (MSE)

SSE를 데이터 포인트 수로 나눈 것.

$$\text{MSE} = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2 = \frac{\text{SSE}}{n}$$

**특징**

- 항상 0 이상 (오차가 없을 때 0)
- **이상치(outlier)에 민감** (오차가 제곱되므로)
- 미분 가능하므로 경사 하강법을 사용한 최적화에 적합

### 2.3 교차 엔트로피 오차 (CEE)

**Cross Entropy Error**: 딥러닝 분류 문제에서 널리 사용. 모델의 예측 확률 분포와 실제 레이블 분포 사이의 차이를 측정.

**단일 데이터 포인트**

$$E = -\sum_{k} t_k \log(y_k)$$

| 기호 | 의미 |
|---|---|
| $t_k$ | 실제 레이블의 $k$번째 요소 (보통 원-핫 인코딩) |
| $y_k$ | 신경망 출력의 $k$번째 요소 (예측 확률) |
| $k$ | 출력 뉴런(또는 클래스)의 인덱스 |

**배치 데이터 (n개)**

$$E = -\frac{1}{n} \sum_{i=1}^{n} \sum_{k} t_{ik} \log(y_{ik})$$

> **미니배치**: 빅데이터는 수백만~수천만 단위가 되어 모든 데이터의 손실 함수를 계산하는 것은 비현실적. 일부를 추려 전체의 근사치로 사용 — **미니배치 학습**.

**이진 분류**

$$E = -\frac{1}{n} \sum_{i=1}^{n} \big[ t_i \log(y_i) + (1 - t_i) \log(1 - y_i) \big]$$

| 기호 | 의미 |
|---|---|
| $t_i$ | 실제 클래스 (0 또는 1) |
| $y_i$ | 양성 클래스에 속할 예측 확률 |

**소프트맥스와 함께 사용 시 편미분**

$$\frac{\partial E}{\partial a_j} = y_j - t_j$$

| 기호 | 의미 |
|---|---|
| $a_j$ | 소프트맥스 이전의 $j$번째 출력 뉴런 값 |
| $y_j$ | 소프트맥스 이후의 $j$번째 확률 값 |
| $t_j$ | $j$번째 클래스의 실제 레이블 값 |

**특징**

- 모델 출력이 실제 레이블에서 멀수록 더 큰 오차
- **소프트맥스와 함께 사용할 때 미분 형태가 깔끔** ($y_j - t_j$)
- 잘못된 예측에 로그적으로 증가하는 페널티 부여
- 희소 레이블(one-hot 벡터)과 작동하도록 설계됨
- **최대 가능도 추정 (MLE)** 과 수학적으로 동등

### 2.4 왜 정확도가 아닌 손실 함수인가?

손실 함수의 궁극적 목적은 정확도를 끌어내는 매개변수 값을 찾는 것. 그런데 정확도가 아닌 손실 함수를 쓰는 이유는?

- **정확도**는 확률적으로 정해져 있어 매개변수를 약간 바꾸어도 값이 거의 변하지 않음 (계단처럼 불연속) → **흐름을 알기 어려움**, 어느 방향으로 매개변수를 조정해야 할지 알 수 없음
- **손실 함수**는 미분을 통해 값이 낮아지는 방향을 찾을 수 있어 흐름을 알 수 있고, 매개변수 값을 조정할 수 있음

## 3. 경사 하강법 (Gradient Descent)

- 머신러닝 문제 대부분은 학습 단계에서 최적의 매개변수를 찾음
- **최적의 매개변수**: 손실 함수가 최솟값이 될 때의 매개변수 값
  - 손실 함수가 최솟값이라는 뜻은 정답에 가깝게 나오는 최적의 매개변수
  - 매개변수 공간이 광대해 어디가 최솟값인지 짐작할 수 없음
- **기울기**를 잘 이용해 함수의 최솟값(또는 가능한 한 작은 값)을 찾으려는 기법
- 최솟값은 기울기가 0이 되는 값 중 하나. 기울기가 낮아지는 방향으로 조금씩 매개변수를 바꾸면 그 값에 도달함
- 단, 기울기가 0이 되는 값이 정말 최솟값인지, 옳은 방향인지는 보장할 수 없음 (지역 최솟값/안장점 가능성). 그럼에도 그 방향으로 가야 함수의 값을 줄일 수 있음

### 3.1 갱신 수식

$$x_0 \leftarrow x_0 - \eta \frac{\partial f}{\partial x_0}$$

$$x_1 \leftarrow x_1 - \eta \frac{\partial f}{\partial x_1}$$

- $\eta$: **학습률 (Learning Rate)**. 한 번의 학습으로 알게 된 기울기(방향)를 따라 얼마만큼 이동할지를 결정
- 위 계산은 1회 갱신. 여러 단계 반복하며 서서히 함수 값을 줄임

### 3.2 학습률의 효과

| 학습률 | 결과 |
|---|---|
| **너무 큼** | 변화값이 너무 커 적절히 최솟값을 찾을 수 없음. 발산 가능성 |
| **너무 작음** | 변화값이 너무 작아 여러 번 반복해야 함 (학습 느림) |

> 보통 1보다 작은 값으로 설정.

![학습률의 영향](images/neural-network-training-02.webp)

- **학습률은 hyper parameter (초매개변수)**. 가중치/편향 같은 신경망 매개변수와는 성질이 다름. 가중치/편향은 학습으로 자동 결정되지만, 학습률은 사람이 직접 설정해야 함

### 3.3 가중치에 대한 손실 함수의 기울기

가중치가 $W$, 손실 함수가 $L$일 때, 각 가중치에 대한 손실 함수의 기울기를 구해야 가중치 값을 최적으로 갱신할 수 있음.

## 4. SGD (Stochastic Gradient Descent)

확률적으로 무작위로 골라낸 데이터를 바탕으로 수행하는 경사 하강법.

![SGD vs 전체 데이터 GD](images/neural-network-training-03.webp)

### 4.1 동기

- 전체 데이터셋으로 최솟값 방향을 잡으면 방향은 올바르지만 데이터가 너무 많아 매우 느림
- **미니배치를 무작위로 선택**해 각 단계에서의 Gradient Descent 계산

### 4.2 특성

- 미니배치 값들의 최솟값을 향하는 기울기로 갱신하므로, 실제 전체 데이터의 최솟값 방향과는 다를 수 있음
- 하지만 한 번 사용한 미니배치를 다시 사용하지 않으므로, 반복하면 결국 전체 데이터의 최솟값 방향으로 수렴
- 즉, **방향은 지그재그**로 가지만 결국 최솟값으로 수렴

| 특성 | 설명 |
|---|---|
| 노이즈 | 존재 (지그재그) |
| 계산 비용 | 전체 데이터셋 GD보다 훨씬 적음 |
| 대규모 데이터셋 | 효율적으로 작동 |
| 지역 최적해 | 빠져나올 가능성 있음 (노이즈 덕분) |

> **지역 최적해**: 최솟값은 아니지만 기울기가 0이 되는 곳. 전역 최솟값(global minimum)이 아닌 국소 최솟값(local minimum).
