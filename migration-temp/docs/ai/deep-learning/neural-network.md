- 퍼셉트론으로 컴퓨터가 수행하는 복잡한 함수도 표현할 수 있음
- 하지만 가중치($w$)를 설정하는 것은 사람이 수동으로 함. 이를 자동으로 해결하기 위해 도입된 개념이 **신경망**

![신경망의 다층 구조](images/neural-network-01.webp)

- 이 다층 구조의 퍼셉트론이 신경망의 예시
- 입력층의 값이 함수를 거쳐 변환되어 출력층까지 변환되어 나옴

## 1. 활성화 함수

- 입력 신호의 총합을 출력 신호로 변환하는 함수를 **활성화 함수(activation function)** 이라 함

$$a = b + w_1 x_1 + w_2 x_2$$

$$y = h(a)$$

- 가중치가 달린 입력 신호와 편향의 총합을 계산한 값을 $a$라 하고, 이를 $h()$ 함수에 넣어 $y$를 출력함

![활성화 함수 도식](images/neural-network-02.webp)

- 특히 $h(a)$가 임곗값($b$)을 경계로 출력이 바뀌는 경우 → **계단 함수 (step function)**
- 즉, 퍼셉트론은 활성화 함수로 계단 함수를 사용한다고 할 수 있음
- 이 계단 함수 이외의 함수로 변경 가능

## 2. 시그모이드 함수

![Sigmoid 함수](images/neural-network-03.webp)

![Sigmoid vs Step](images/neural-network-04.webp)

- 계단 함수와 비교하여, 시그모이드 함수는 **부드러운 곡선**이며, 입력에 따라 출력이 연속적으로 변함
- 이 매끄러움 덕분에 퍼셉트론에서는 뉴런 사이에 0 또는 1만 흘렀다면, **신경망에서는 연속적인 실수가 흐름**
- 큰 관점에서는 비슷한 모습. 입력이 작을 때 출력이 0에 가깝고, 입력이 커지면 1에 가까워지는 구조
- 둘 다 **비선형 함수**

> **왜 비선형 함수를 사용해야 하는가?**
> 선형 함수를 활성화 함수로 사용하면 신경망의 층을 깊게 하는 의미가 없어짐.
> 예: $h(x) = ax + b$의 경우, 층을 깊게 해 $h(h(h(x)))$로 만들어도 결국 $a' x + b'$ 형태에서 벗어날 수 없음.

### 2.1 ReLU (Rectified Linear Unit)

- 최근에 주로 이용하는 함수
- 입력이 0을 넘으면 그 입력을 그대로 출력, 0 이하면 0을 출력

$$
h(x) = \begin{cases}
x & (x > 0) \\
0 & (x \leq 0)
\end{cases}
$$

![ReLU 함수](images/neural-network-05.webp)

## 3. 소프트맥스 함수

분류에서 사용하는 함수.

$$\text{softmax}(z_i) = \frac{e^{z_i}}{\sum_{j=1}^{n} e^{z_j}}$$

### 3.1 오버플로우 문제

- 지수 함수는 매우 높은 값을 출력할 수 있음
- 큰 값끼리의 나눗셈은 수치가 불안정 → 개선 수식 필요

### 3.2 소프트맥스 개선 (수식 유도)

**1. 분모와 분자에 상수 $C$ 곱하기** (값은 변하지 않음)

$$\text{softmax}(z_i) = \frac{C \cdot e^{z_i}}{C \cdot \sum_{j=1}^{n} e^{z_j}}$$

**2. $C = e^{\log C}$로 치환**

$$\text{softmax}(z_i) = \frac{e^{\log C} \cdot e^{z_i}}{e^{\log C} \cdot \sum_{j=1}^{n} e^{z_j}}$$

**3. 지수 법칙 $e^a \cdot e^b = e^{a+b}$ 적용**

$$\text{softmax}(z_i) = \frac{e^{z_i + \log C}}{\sum_{j=1}^{n} e^{z_j + \log C}}$$

**4. $\log C = C_1$로 치환**

$$\text{softmax}(z_i) = \frac{e^{z_i + C_1}}{\sum_{j=1}^{n} e^{z_j + C_1}}$$

### 3.3 안정화 트릭

- $C_1$에 **$z$ 값들 중 최댓값의 음수**(즉 $-\max(z)$)를 사용하면 최댓값이 0이 되고, 이를 기준으로 값들이 평준화됨
- 무한대로 치솟는 값을 억제할 수 있음

### 3.4 소프트맥스 함수의 특징

- **0 ~ 1 사이의 값** (출력값의 총합이 1)
- 출력을 **확률로 해석** 가능
- 원래 함수와 비교해 **대소가 바뀌지 않음** (단조 증가 함수)
- 분류에서는 일반적으로 **가장 큰 출력**을 내는 뉴런에 해당하는 클래스로 인식
- 소프트맥스를 적용해도 **출력이 가장 큰 뉴런의 위치는 달라지지 않음**
- 신경망으로 **분류만 할 때**는 출력층의 소프트맥스 함수를 생략해도 됨. 현업에서도 지수 함수 계산의 자원 낭비를 줄이고자 추론 시 출력층의 소프트맥스를 생략

### 3.5 argmax()

- 축을 기준으로 최댓값의 index를 가져오는 함수. 소프트맥스와 함께 자주 쓰임
- `axis`: 축을 어떻게 할지 결정. 0이면 0차원, 1이면 1차원을 축으로 잡음
