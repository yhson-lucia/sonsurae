## 1. 웹을 구성하는 요소

웹 개발은 브라우저와 소통하기 위한 프로그래밍 언어로 구성됨. 주로 **HTML, CSS, JavaScript** 사용.

| 언어 | 역할 |
|---|---|
| **HTML** (HyperText Markup Language) | 웹 페이지의 **구조** 정의. 정보·구역 설정 (제목·본문·이미지 등 배치) |
| **CSS** (Cascading Style Sheets) | 웹 페이지의 **스타일** 지정. 폰트·색상·레이아웃 등 시각적 디자인 |
| **JavaScript** | 웹 페이지에 **동적 기능** 추가. 이벤트 처리, 애니메이션, 데이터 처리 |

### 1.1 웹사이트 제작 시 고려사항

- **웹 표준**: 웹사이트 개발 시 따르는 공식적인 규칙·기술 규격. 다양한 브라우저·환경에서 일관된 동작 보장
- **웹 접근성**: 장애 여부와 관계없이 모든 사용자가 웹사이트를 쉽게 접근·사용할 수 있도록 하는 설계 원칙
- **크로스 브라우징 (Cross-Browsing)**: 다양한 브라우저에서 동일한 웹사이트가 정상 작동하도록 하는 기술

## 2. HTML 기본 태그

- **HTML**은 웹사이트에서 정보를 표시하고 구역을 설정하는 언어
- 네비게이션, 배너, 로그인, 언론사 등 주요 구역에 특정 정보를 나타내는 구역 설정도 HTML이 담당

### 2.1 HTML 태그의 구조

```html
<열린태그 속성="속성값">컨텐츠</닫힌태그>
```

| 요소 | 설명 |
|---|---|
| **태그명** | HTML 고유 키워드 (예: `<p>` = 문단) |
| **컨텐츠** | 태그 사이에 들어가는 내용. 화면에 표시 |
| **속성** | 태그가 추가 정보를 제공하는 방법 |
| **속성값** | 속성이 수행할 동작·정보를 구체적으로 지정 |

### 2.2 HTML 문서의 기본 구조

```html
<!DOCTYPE html>           <!-- 문서가 HTML5로 작성되었음을 명시 -->
<html>
  <head>
    <meta charset="UTF-8">  <!-- 문서의 문자 인코딩 -->
    <title>문서 제목</title> <!-- 브라우저 상단의 제목 -->
  </head>
  <body>
    <h1 style="color: navy;">제목</h1>
    <p>여기에 본문 내용이 들어갑니다.</p>
    <img src="logo.png" alt="회사 로고">
  </body>
</html>
```

### 2.3 주요 HTML 태그

| 태그 | 설명 |
|---|---|
| `<!DOCTYPE html>` | 문서가 HTML5 규격을 따름을 선언 |
| `<html>` | HTML 문서의 시작·끝 |
| `<head>` | 메타데이터 포함. 화면에 보이지 않음 |
| `<body>` | 실제 표시되는 콘텐츠 |
| `<meta charset="UTF-8">` | 문자 인코딩 UTF-8 설정 |
| `<title>` | 브라우저 탭에 표시되는 페이지 제목 |
| `<h1> ~ <h6>` | 제목. h1이 가장 중요, h6가 가장 덜 중요 |
| `<p>` | 문단 (Paragraph) |
| `<img>` | 이미지 삽입. `src`로 경로 지정, `alt`로 대체 텍스트 제공 |

## 3. HTML의 구조를 잡는 태그 (시맨틱 태그)

웹 페이지의 구조를 정의. 웹사이트의 목차·본문·부록을 구분하는 데 사용.

### 3.1 `<header>`

웹사이트의 머리글 영역. 로고, 제목, 네비게이션 메뉴 등 포함.

```html
<header>
  <img src="logo.png" alt="회사 로고">
  <nav>
    <ul>
      <li><a href="#home">홈</a></li>
      <li><a href="#about">소개</a></li>
    </ul>
  </nav>
</header>
```

### 3.2 `<nav>`

네비게이션 영역. 메뉴 항목을 목록으로 표시.

### 3.3 `<main>`

문서의 주요 콘텐츠. Internet Explorer에서 미지원이므로 `role="main"` 속성으로 명시.

```html
<main role="main">
  <article>
    <h2>게시글 제목</h2>
    <p>게시글 내용이 여기에 있습니다.</p>
  </article>
</main>
```

### 3.4 기타 시맨틱 태그

| 태그 | 설명 |
|---|---|
| `<article>` | 독립적인 콘텐츠 블록 (뉴스 기사, 블로그 게시물 등) |
| `<footer>` | 웹 페이지 하단 영역 (저작권·연락처) |
| `<div>` | 별도 의미 없이 구역을 나누는 데 사용. 레이아웃 구성 |

## 4. HTML 태그의 두 가지 성격

HTML 태그는 **Block 요소**와 **Inline 요소**로 구분.

| 구분 | Block 요소 | Inline 요소 |
|---|---|---|
| 정렬 | Y축 정렬 (줄바꿈 발생) | X축 정렬 (같은 줄에 표시) |
| 너비 | 화면 전체 너비 차지 | 컨텐츠 만큼만 차지 |
| 배치 | 상하 배치 가능 | 줄바꿈 없이 연속 배치 |
| 대표 태그 | `<p>`, `<h1>`, `<div>`, `<header>`, `<section>` | `<a>`, `<img>`, `<span>`, `<strong>` |
