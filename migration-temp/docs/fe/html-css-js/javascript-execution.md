## 1. 자바스크립트 변수 정의 과정

### 1.1 자바스크립트 엔진

- 자바스크립트 코드를 읽어 실행하는 프로그램
- 작성한 JS 코드는 엔진을 통해 파싱·실행
- Chrome은 **V8 엔진** 사용
- **Node.js**: 브라우저 외 환경에서 JS를 실행하도록 하는 프로그램. V8을 사용하지만 브라우저 환경과 같은 코드를 입력해도 다르게 동작할 수 있음

### 1.2 자바스크립트 코드 실행

자바스크립트 엔진이 코드 실행 전 **실행 컨텍스트(Execution Context)** 를 생성.

| 단계 | 동작 |
|---|---|
| **생성 단계** | 변수 선언을 읽음 |
| **실행 단계** | 변수에 값을 할당 |

### 1.3 렉시컬 환경 (Lexical Environment)

- 함수의 렉시컬 환경: **함수가 사용하는 변수들을 둘러싼 환경**
- 특정 변수의 값은 함수의 렉시컬 환경 안에서 찾을 수 있음
- 실행 컨텍스트 안에 정의된 **Variable Object**로 이해 가능

### 1.4 단계별 코드 실행

**생성 단계**

- 엔진은 함수 선언문, 함수 표현식, 변수 등을 읽어 실행 컨텍스트에 저장
- 변수의 경우 실행 컨텍스트의 렉시컬 환경을 구성
- 함수 선언문 외의 변수는 값이 저장되지 않음

**실행 단계**

- 엔진이 변수에 값을 할당하는 구문을 만나면 실행 컨텍스트에 값을 저장
- 코드를 한 줄씩 읽어 나가며 실행

## 2. 자바스크립트 Hoisting

코드 실행 시 변수 처리.

- 자바스크립트 엔진이 코드를 읽을 때 **생성 단계에서 실행 컨텍스트 생성**
- 함수 선언문은 생성 단계에서 함수 전체가 실행 컨텍스트에 저장
- `var` 변수는 저장 시 **`undefined`로 초기화**
- `let`, `const`는 초기화되지 않음

### 2.1 변수 선언 키워드 비교

| 키워드 | 재할당 | 스코프 |
|---|---|---|
| `var` | 가능 | 함수 스코프 |
| `let` | 가능 | 블록 스코프 |
| `const` | 불가능 | 블록 스코프 |

## 3. 자바스크립트 내장 객체

자바스크립트는 여러 용도에 활용하는 객체를 내장하고 있음 (숫자·문자·날짜·JSON 다루기).

### 3.1 globalThis

- 전역 객체를 지칭하는 변수
- 전역 객체는 환경에 따라 다름
  - 브라우저: `window`
  - Node: `global`
- `globalThis`는 환경별 차이를 통일해 하나의 변수로 서로 다른 전역 객체를 가리킴

### 3.2 Number, NaN

- **Number**: 자바스크립트의 number 원시 타입을 감싸는 객체. 유의미한 상수, 숫자 변환 메서드 제공
- **NaN** (Not a Number): NaN을 나타내는 값
- **`isNaN()`**: 전역 함수. 입력값을 숫자로 변환했을 때 NaN이 되는지 검사

### 3.3 Math

- 기본적인 수학 연산 메서드·상수를 다루는 객체
- BigInt 타입과 호환되지 않음. **Number 타입만** 인자로 다룸

### 3.4 Date

- 특정 시점의 날짜를 표시하기 위한 객체
- 날짜와 관련된 작업을 위한 여러 메서드 포함

### 3.5 String, JSON

- **String**: 자바스크립트 문자열 원시 타입의 래퍼 객체. 문자열 조작 메서드 다수
- **JSON**: JSON 객체와 관련된 메서드를 담은 객체
