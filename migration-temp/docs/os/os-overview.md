## 1. 운영체제 (OS)

- 컴퓨터 하드웨어 바로 위에 설치되어 사용자·소프트웨어와 하드웨어를 연결하는 **소프트웨어 계층**

### 1.1 운영체제의 목적

사용자에게 편리함 제공 + 자원의 효율적 관리.

- 동시 사용자/프로그램들이 각각 독자적인 컴퓨터에서 수행되는 듯한 환상(illusion) 제공
- 하드웨어를 직접 다루는 복잡한 부분을 OS가 대행
- 시스템 자원(CPU, 메모리, I/O 장치)을 효율적으로 관리
- 특정 프로그램·사용자에게 지나친 불이익이 가지 않도록 형평성 유지

### 1.2 컴퓨터 내부 구성

- **CPU + 메모리**가 핵심
- **I/O 디바이스**: 디스크, 키보드, 프린터 등

## 2. OS의 주요 기능

- 부팅 시 메모리에 OS가 가장 먼저 올라가 시작됨
- I/O device는 각자 controller(작은 CPU)를 가짐. CPU 요청을 받으면 데이터 제공
- **CPU 스케줄링**: OS가 CPU를 가지고 있으면서 프로그램에 사용권을 할당
- **메모리 관리**
- **디스크 스케줄링**: 디스크 요청 처리 시간(매우 느림) 동안 다른 프로그램으로 넘어감. 동시 요청 중 가장 빨리 처리할 수 있는 것을 우선 처리 (엘리베이터 모델)
- **인터럽트, 캐싱**: CPU와 I/O 속도 차이를 극복
  - **캐싱**: 메모리에 데이터를 보관해 두고 같은 요청 시 디스크가 아닌 메모리에서 가져옴
  - **인터럽트**: CPU 사용 권한을 OS로 넘김. 입출력 요청 처리 후 데이터를 받을 때 OS로 CPU를 가져와 해당 프로그램을 실행

## 3. 프로세스

- **실행 중인 프로그램**을 프로세스라 함
- 각각의 큐가 존재. 스케줄링에 의해 옮겨짐
- 예: 디스크 입출력 큐 → CPU 큐로 이동

## 4. 운영체제의 종류

- 서버용, PC용, 스마트 디바이스용 OS
- **Linux** (공개 소프트웨어)

> **OS를 공개하는 이유?** 소프트웨어는 인건비가 들지만 추가 비용은 거의 없음 → 독점 체제가 가능한 시장. 성능과 무관하게 2~3등은 모두 망함. 공개하면 필요에 맞게 수정·업데이트할 수 있다는 강력한 무기가 됨.
