## 1. 컴퓨터 개요

### 1.1 프로그램 vs 프로세스

- **프로그램**: 실행 가능한 형태의 파일에 저장된 명령어 집합 (예: exe 파일)
- **프로세스**: 프로그램이 실행되어 OS에 의해 메인 메모리에 적재(load)된 상태

CPU와 메모리가 가장 중요함.

- **CPU**: 제어와 연산 담당
- **메모리**: 기억 담당

### 1.2 프로그래밍 언어

- **기계어 (Machine code)**: 2진수로 표현된 컴퓨터의 언어. 같은 2진수라도 CPU 아키텍처에 따라 다름
- **bit / byte**
  - bit: 0 또는 1을 표현하는 최소 단위
  - byte: 8개 비트 묶음. 메인 메모리의 기본 저장 단위
- **어셈블리 언어 (Assembly Language)**: 기계어와 1:1 대응하는 단어 기반 언어. 명령어 셋마다 문법이 다름
- **저수준 언어 (low-level)**: 기계어 수준에 가까운 언어
- **고수준 언어 (high-level)**: 사람의 자연어 수준에 가까운 언어

기계어와 사람의 언어가 다르므로 가교 역할을 하는 것이 **프로그래밍 언어**.

## 2. Java

- 첫 시작은 가전제품 컨트롤 칩 개발용 언어. 제품마다 표준이 없어 불편했던 문제를 해결
- 1996년 첫 출시
- **OpenJDK**라는 이름으로 오픈소스화. JDK는 자바 개발용 툴
- **컴파일**: 고수준 언어를 저수준 언어(기계어)로 변환하는 과정
- CPU 아키텍처마다 기계어가 다르기 때문에 C/C++ 같은 언어는 CPU에 맞춰 컴파일해야 함
- Java는 **JVM (Java Virtual Machine)** 을 통해 중계 역할을 해 이러한 불편을 해결
- Java는 **표준 스펙**이 있어 여러 회사가 구현체를 제공함 (Oracle OpenJDK, Adoptium Eclipse Temurin, Amazon Corretto 등)

### 2.1 JVM (Java Virtual Machine)

- macOS의 Parallels, VirtualBox, Android 가상화를 위한 BlueStacks와 비슷한 개념
- 특정 OS를 다른 OS 위에서 가상으로 실행하는 OS 가상화. 이로 인해 환경에 무관하게 동일한 동작을 보장함
- **가상화 목적**: 프로그램에 균일한 실행 환경 제공. 어느 환경에서든 Java 코드를 실행했을 때 동일한 결과를 얻기 위함

### 2.2 JRE (Java Runtime Environment)

- Java 애플리케이션 실행에 필요한 소프트웨어. **JVM이 포함됨**

### 2.3 JDK (Java Development Kit)

- Java 언어로 애플리케이션을 개발할 때 필요한 툴 셋

## 3. 자료형

- 컴퓨터는 **byte 단위**로 데이터를 보관. 1byte에 들어가지 않는 값은 2byte 이상 사용
- 사람이 다루는 데이터는 자연수, 실수, 문자, 논리형 등 여러 종류
- 어디서부터 어디까지가 어떤 데이터인지 구분이 필요. 자료형은 데이터 크기가 정해진 그릇을 제공함 (메모리의 연속된 byte 공간)
- 예: 정수는 1byte ~ 8byte까지 4가지 그릇 제공. 자연수 크기에 따라 적절한 자료형 선택

자료형 분류

- **기본형**: 실제 데이터를 직접 담는 자료형 — `byte`, `short`, `int`, `long`, `char`, `boolean`, `float`, `double`
- **참조형**: 실제 데이터가 위치한 메모리 주소를 담는 자료형. 기본형 이외의 모든 자료형
  - 가변 크기 데이터, 복합 데이터, 복제하기 어려운 큰 데이터 등에 사용

### 3.1 정수형 (Integer)

Java의 정수형은 음의 정수와 양의 정수를 모두 포함.

| 자료형 | 크기 | 비고 |
|---|---|---|
| `byte` | 1 byte | |
| `short` | 2 byte | |
| `int` | 4 byte | 정수형 기본 타입 |
| `long` | 8 byte | |

### 3.2 문자형 (Character)

- **유니코드 (Unicode)**: 세계 각국의 언어를 Code Point로 표현 (16진수)
- **UTF-16 인코딩**으로 사람의 문자를 컴퓨터가 이해할 수 있는 2진수로 변환

| 표기 | 값 |
|---|---|
| `char c1` | `'A'` |
| `char c2` | `65` |
| `char c3` | `0x41` |
| `char c4` | `0b00000000_01000001` |

### 3.3 논리형

- **boolean**: 참/거짓을 의미. `true`, `false` 두 값
- 참/거짓 판단을 위해 비교 연산자를 사용

비교 연산자

| 연산자 | 의미 |
|---|---|
| `==` | 좌·우항이 같으면 `true`, 다르면 `false` |
| `!=` | 좌·우항이 다르면 `true`, 같으면 `false` |
| `>=` | 좌항이 우항보다 크거나 같으면 `true` |
| `<=` | 좌항이 우항보다 작거나 같으면 `true` |
| `.equals()` | 메서드. 주로 `String`에서 두 문자열 동일성 비교에 사용 |

**논리 연산자 (Logical Operator)**

- **Short-circuit Evaluation**: 논리 곱(`&&`)은 false가 있으면 false, 논리 합(`||`)은 true가 있으면 true. 가장 왼쪽 연산만 계산하고 나머지는 건너뜀

### 3.4 실수형 (Real)

- `float`: 4 byte
- `double`: 8 byte. **실수형 기본 타입**

컴퓨터에서 실수를 2진수로 표현하는 방식은 두 가지.

1. **고정 소수점 (Fixed point)**: 소수점 위치 고정. 연산 속도 빠름
2. **부동 소수점 (Floating point)**: 지수부 + 가수부. 정밀한 소수 표현 가능하지만 연산 상대적으로 느림

부동 소수점은 정확한 실수를 표현하지 못함 (10진수 → 2진수 변환 시 무한 반복 소수가 발생할 수 있음).

### 3.5 변수 (Variable)

- 대입되는 값에 따라 변하는 것 (수학의 변수와 다름)
- **선언 (declaration)** + **할당 (assignment)** 으로 구성
- 선언: "데이터를 저장하기 위해 일정 공간을 사용한다"
- 값 할당: "할당된 공간에 특정 데이터를 저장한다"
- 자료형에 따라 메모리 사이즈가 정해지고, 값 할당으로 저장 공간에 값이 저장됨
- 변수는 OS로부터 할당받은 공간의 주소를 기억함
- **명명 규칙**: camelCase

### 3.6 상수 (Constant)

- **리터럴 (literal)**: 값 그 자체 (예: `1`, `'A'`, `3.14`)
- **final 상수**: 값을 재할당할 수 없는 변수. 나만의 상수를 정의할 때 사용
  - **명명 규칙**: 대문자 + snake_case (예: `MAX_COUNT`)

### 3.7 형변환 (Type Casting)

하나의 타입에서 다른 타입으로 바꾸는 행위.

- 작은 타입 → 큰 타입은 안전 (예: `short` → `int`)
- 큰 타입 → 작은 타입은 데이터 유실 가능성. 주의 필요
- 두 가지 방식
  - **묵시적 형변환**: Java 컴파일러가 자동 변환. 문제가 생긴다고 판단되면 에러
  - **명시적 형변환**: 개발자가 강제로 변환. 책임은 개발자에게
- **상수값 대입 시 형변환**: 리터럴이 특정 타입의 변수에 할당될 때 발생

### 3.8 삼항 연산자 (Ternary Operator)

조건식이 참/거짓에 따라 다른 값을 반환하는 연산자.

```
<조건식> ? <참일 때 값/표현> : <거짓일 때 값/표현>
```

- **문 (statement)**: 값으로 대체되지 않는 코드
- **식 (expression)**: 값으로 대체될 수 있는 코드

### 3.9 제어문

- `if` 문 (if statement)
- `switch` 문 (switch statement)

### 3.10 반복문 (Loop)

- `for` loop
- `while` loop
- `do-while` loop
