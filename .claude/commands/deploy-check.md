# 🚀 배포 전 체크리스트

Vercel 프로덕션 배포 전 종합 점검을 수행합니다.

## 작업 순서

### 1. 빌드 검증
```bash
npm run build
```
- 빌드 성공 여부
- 타입 에러 없음
- 번들 크기 합리적

### 2. 린트 검증
```bash
npm run lint
```
- ESLint 에러 0
- 경고 검토

### 3. 검증 에이전트 병렬 실행

다음 3개를 **병렬 호출**:

1. **code-reviewer agent**: 전체 코드 품질 점검
2. **security-auditor agent**: 보안 종합 감사
3. **seo-optimizer agent**: 메인 페이지들 SEO 점검

### 4. 환경 변수 검증
- `.env.local`에 모든 필수 변수 존재
- Vercel Dashboard 환경 변수 매칭 확인 (사용자에게 확인 요청)
- `NEXT_PUBLIC_` 접두사 적절히 사용

### 5. Git 상태 점검
```bash
git status
git diff
```
- 커밋되지 않은 중요 변경 없음
- `.gitignore` 적절히 적용 (`.env.local` 제외 등)

### 6. 의존성 보안 점검
```bash
npm audit
```
- Critical/High 취약점 없음

### 7. 최종 보고

```markdown
## 🚀 배포 준비 상태

### ✅ 통과 항목
- [ ] 빌드 성공
- [ ] 린트 통과
- [ ] 타입 체크 통과
- [ ] 코드 리뷰 통과
- [ ] 보안 감사 통과
- [ ] SEO 점수 양호
- [ ] 환경변수 설정 완료
- [ ] Git 상태 정상
- [ ] 의존성 취약점 없음

### ⚠️ 경고 사항
- [경미한 이슈들]

### 🔴 차단 사항
- [배포 막아야 할 이슈]

### 🎯 배포 권장 여부
- ✅ 배포 가능
- ⚠️ 경고 사항 검토 후 배포
- ❌ 수정 필요 (배포 X)
```

## 주의사항
- 차단 사항이 있으면 절대 배포 권장하지 말 것
- 경고 사항도 사용자에게 명확히 전달
- 배포는 사용자가 최종 결정 (자동 배포 X)
